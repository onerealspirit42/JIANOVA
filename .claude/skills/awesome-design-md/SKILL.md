# Awesome DESIGN.md (reference library)

A copy of [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(commit fcc7028, MIT licence in `LICENSE`). Each folder in `design-md/<brand>/`
holds a `DESIGN.md`: a plain-text analysis of that site's design system
(tokens, typography, layout, components, rules).

## How to use it on JIANOVA

1. Pick the references that fit the question. For a premium running-shoe
   brand the closest are `apple`, `nike`, `oura`, `tesla`, `bmw`, `ferrari`
   and `spotify`; list `design-md/` for the rest.
2. Read the reference's `DESIGN.md` and take **principles**, not the look:
   how it spaces sections, sizes type, uses colour and shows the product.
3. Never copy another brand's colours, logo, typefaces, copy or signature
   layout. JIANOVA keeps its own identity: royal purple `#241039`, the
   four-pointed star logo (the wordmark's A has no crossbar), Instrument Serif
   and Sans with Noto Naskh Arabic and IBM Plex Sans Arabic, and the taste
   skill's system in `apps/web/public/assets`.
4. When the design brief and a reference disagree, the brief wins.

## Updating

Re-copy `design-md/` from the upstream repository and note the new commit here.
